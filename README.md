## Deskripsi

Website **Ocean Kitchen** adalah platform pemesanan roti berbasis *Pre-Order* (PO) untuk bisnis *home bakery*. Website ini memfasilitasi pelanggan untuk melihat katalog produk, informasi ongkos kirim, dan memesan sesuai jadwal PO. Selain itu, sistem ini membantu pengelola dalam mencatat bahan baku, menghitung Harga Pokok Produksi (HPP), memverifikasi pembayaran, serta mengelola laporan penjualan.
